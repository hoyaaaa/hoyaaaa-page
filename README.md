# Changho Park — personal site

Personal portfolio and PDF résumé for [hoyaaaa.is-a.dev](https://hoyaaaa.is-a.dev).

The site presents my current work as a backend engineer, selected public
projects, career history, and a bilingual PDF résumé generated in the browser.

## Stack

- React 18 and Vite
- React Router
- `@react-pdf/renderer`
- Plain CSS with locally hosted Noto Sans KR fonts

## Development

```sh
npm ci
npm run dev
```

Create a production build with:

```sh
npm run build
```

## Deployment

The `main` branch is deployed to Cloudflare Pages and served at
`hoyaaaa.is-a.dev`.
